Operating Systems

Background | Processes | Memory | Scheduling & I/O | Advanced Architectures | Distributed Systems

Part One: Background

Hardware and conceptual groundwork used throughout the rest of the course.

Chapter 1: Computer System Overview
Topics: processor and register organization, interrupts, memory hierarchy and cache, I/O structuring, multicore basics
Chapter 2: Operating System Overview
Topics: OS objectives, evolution from batch to time-sharing systems, monolithic vs. microkernel vs. layered design, case studies (Linux, Windows 10, Android)

Part Two: Processes

How the OS represents and manages execution, and what goes wrong when it is shared.

Chapter 3: Process Description and Control
Topics: process states and transitions, process control block, process creation and termination, modes of execution, UNIX SVR4 process management
Chapter 4: Threads
Topics: process vs. thread, user-level vs. kernel-level threads, multithreading models, thread pools, Windows/Linux thread implementation
Chapter 5: Concurrency: Mutual Exclusion and Synchronization
Topics: race conditions and critical sections, software/hardware mutual exclusion, semaphores, monitors, message passing
Chapter 6: Concurrency: Deadlock and Starvation
Topics: conditions for deadlock, prevention/avoidance/detection, Banker's algorithm, dining philosophers, UNIX/Linux deadlock handling

Part Three: Memory

Giving every process the illusion of private, unlimited memory.

Chapter 7: Memory Management
Topics: fixed and dynamic partitioning, paging, segmentation, address translation basics
Chapter 8: Virtual Memory
Topics: demand paging, page replacement (LRU, FIFO, clock), thrashing, working-set model, translation lookaside buffers

Part Four: Scheduling and I/O

Deciding who runs next, and moving data between memory and the outside world.

Chapter 9: Uniprocessor Scheduling
Topics: scheduling criteria, FCFS, SJF, priority scheduling, round robin, multilevel feedback queues
Chapter 10: Multiprocessor, Multicore, and Real-Time Scheduling
Topics: SMP scheduling, load balancing and affinity, rate monotonic scheduling, earliest deadline first
Chapter 11: I/O Management and Disk Scheduling
Topics: I/O device classes, buffering, disk scheduling (SSTF, SCAN, C-SCAN), RAID
Chapter 12: File Management
Topics: file organization and directories, allocation methods (contiguous, linked, indexed), free-space management, journaling

Part Five: Advanced Architectures

Where OS design meets tiny devices, shared hardware, security threats, and rented infrastructure.

Chapter 13: Embedded Operating Systems
Topics: real-time requirements, memory and footprint constraints, RTOS design
Chapter 14: Virtual Machines
Topics: Type 1 vs. Type 2 hypervisors, full virtualization vs. paravirtualization, containers vs. VMs
Chapter 15: Operating System Security
Topics: access control models, authentication, buffer overflow and exploitation basics, trusted systems
Chapter 16: Cloud and IoT Operating Systems
Topics: cloud service and deployment models, resource pooling and elasticity, constrained-device OS design

Part Six: Networked and Distributed Systems

Single-machine ideas renegotiated across a network with no shared memory or clock.

Chapter 17: Networking
Topics: protocol architectures (TCP/IP), sockets, network OS support
Chapter 18: Distributed Processing, Client/Server, and Clusters
Topics: client/server models, clustering approaches, middleware
Chapter 19: Distributed Process Management
Topics: process migration, distributed global states, distributed mutual exclusion and election algorithms
Based on William Stallings, Operating Systems: Internals and Design Principles, 9th Edition, Pearson, 2018.
